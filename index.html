Teambuilding-Workshop

Wer ist es?Die KI‑Team‑Challenge

Workshop „Vibecoding & Personality Matching“: Teams bauen mit Generative AI eine App, die Kolleginnen und Kollegen anhand anonymer Beschreibungen erkennt – ganz ohne Programmiererfahrung.

Präsentationstemplate (Gemini) ↗ Notebook in Colab ↗ Workshop-Folien

Das Prinzip

Was ist Vibecoding?

Software entsteht nicht durch manuelles Schreiben jeder Zeile Code, sondern durch natürliche Sprache: Wir beschreiben Vision und Logik – die KI schreibt den Python-Code.

Traditionelles Coding

  • Syntax lernen
  • Semikolons suchen
  • Debugging, Debugging, Debugging
vs.

Vibecoding

  • Idee in eigenen Worten beschreiben
  • KI schreibt den Code
  • Testen, nachschärfen, fertig
Die Mission

Eine „Wer ist es?“-App in Google Colab

Drei Phasen, ein Ziel: die meisten Kolleginnen und Kollegen richtig erraten.

1

Data

Anonyme Persönlichkeitsprofile sammeln: Hobbys, Ticks, Lieblings-BMW-Modell.

2

Code

Die Logik mit Python und der Gemini API per Prompt von der KI bauen lassen.

3

Test

Live-Challenge: Welches Team errät die meisten Kolleginnen und Kollegen?

Setup

In zwei Schritten startklar

Alles läuft im Browser mit Google Colab – keine lokale Installation nötig.

1 · API Key erstellen

  1. Google AI Studio öffnen.
  2. Auf „Get API key“ klicken.
  3. Den Key in Colab unter Secrets (Schlüssel-Icon links) als GOOGLE_API_KEY speichern.

2 · Bibliothek installieren

In der ersten Zelle des Colab-Notebooks:

!pip install -q -U google-genai
Anatomie der Lösung

Daten + System Prompt = fertig

Ein Grundgerüst als Orientierung für eure Prompts an die KI.

Datenstruktur

Eine Liste von Dictionaries hält die „Wahrheit“:

python
team_data = [
    {"name": "Max M.",
     "desc": "Fährt einen E30, liebt Klettern
              und trinkt nur Espresso."},
    {"name": "Julia S.",
     "desc": "Hat immer die neuesten Gadgets
              und wandert jedes Wochenende."},
    # ... weitere Kollegen
]

Der System Prompt

Das Herzstück der KI-Steuerung:

„Du bist ein KI-Assistent, dessen Aufgabe es ist, einen Mitarbeiter aus einer vorgegebenen Liste zu identifizieren. Der Benutzer wird dir Hobbys und Eigenschaften nennen, und du musst den Namen des Mitarbeiters zurückgeben, der am besten zu diesen Beschreibungen passt. Antworte ausschließlich mit dem Namen.“
Prompting-Tipps

Damit die KI genau das tut, was ihr wollt

⌁

Kontext setzen

„Erstelle eine Python-Liste team_data mit Namen und Beschreibungen.“

◎

Rolle definieren

„Dein fachliches Know-how liegt im Matching von Personenbeschreibungen.“

→

Output steuern

„Wichtig: Die KI soll NUR den Namen ausgeben – keine Erklärungen, keine Sätze drumherum.“

+1pro korrekt identifizierter Kollegin bzw. identifiziertem Kollegen
